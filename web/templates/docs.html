Connect to the server

Default address: http://127.0.0.1:5000. All endpoints are local. No API key or daily budget is required.

In Hybrid Translator, configure the translation provider that accepts a local /translate endpoint with this address. Enable its fallback manually when you want to use the local engine.

POST /translate

Translate plain text

Send a JSON object. Source defaults to auto; target defaults to en. Translation between two other languages goes through English automatically.

{"q": "Hello world", "source": "auto", "target": "en", "format": "text"}

Example response:

{"translatedText": "Hello world", "route": ["en"],
 "detectedLanguage": {"language": "en", "confidence": 90.0}}

For a batch, set q to a list of strings. translatedText will be a list in the same order; routes contains each route. Form fields are also accepted. This endpoint supports plain text; send format: text.

POST /detect

Detect the source language

{"q": "Bonjour tout le monde"}

Returns a list such as [{"language":"fr","confidence":99.0}]. Confidence ranges from 0 to 100. Short labels and shared Chinese/Japanese characters can be ambiguous; choose the source explicitly when needed.

GET /languages

Available language codes

Returns language objects with code, English name, and supported targets. Check model readiness before translating. Install additional languages using the commands on the Models page; restart the server afterward. The returned list reflects your configured collection.

enzh-Hanszh-Hantvithruptesfrja

Aliases zh, zt, zh-CN, zh-TW and pt-BR are accepted. Portuguese uses a generic model by default; the optional Brazilian model uses code pb.

GET /health

Check server and models

/health reports server availability and modelsReady. /studio/status lists installed/missing routes. The Models page provides a readable overview. /frontend/settings returns default languages and per-request limits.

Limits and errors

A request may contain up to 30 items and 64,000 characters in total, with a maximum 1 MiB request body. There is no daily or hourly translation quota.

StatusMeaning
400Invalid text, language, format, or item count
404Unknown page or endpoint
413Request body too large
503Required model is missing or output exceeded its limit
500The engine could not complete the request

Errors contain an English error message. Install missing models with start.bat --setup-only or bash start.sh --setup-only.
