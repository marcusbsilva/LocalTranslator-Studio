Local Translator Studio

An independent Python application for offline text translation.

Translation engine

CTranslate2 executes local neural translation weights. SentencePiece and a BPE tokenizer prepare text. A local language detector selects the source, and a bounded sentence splitter handles long text.

Privacy

The server binds to 127.0.0.1. Your text is processed locally and is not saved by the application. No analytics, remote fonts, external scripts, or runtime model downloads are used by these pages.

Your preferences

Choose Light or Dark in the header. The choice is stored in your browser and applied to every page. The translator defaults to language detection and English output.

Connect your extension

Hybrid Translator on GitHub can use this server's compatible text-translation endpoint. See the API Guide for details.

Source and credits

The application source is available from the footer. Translation weights and bundled fonts keep their original notices and licenses. See third-party licenses and credits.
