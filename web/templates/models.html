How model management works
Installation downloads and validates both translation directions in the background. Keep the server running until the operation completes. The collection updates without restarting the server; reopen or reload an existing Translate tab to update its language dropdowns.
Removal deletes both installed directions and their cached archives. Removed default languages stay removed after startup. English cannot be removed because it connects the other languages. A model operation waits for active translations before deleting weights.
Internet is needed only for new downloads and catalogue refreshes. Model quality varies; translating through English can compound errors. Optional archives record a checksum from their first official HTTPS download. Later copies are checked against that local receipt.


Prefer the command line?
Stop the server before using model-management commands in another terminal. Windows CMD:
start.bat --list-languages
start.bat --install-languages de it ko
start.bat --remove-languages de it
start.bat --install-all-languages
Linux:
bash start.sh --list-languages
bash start.sh --install-languages de it ko
bash start.sh --remove-languages de it
bash start.sh --install-all-languages
Run the launcher again afterward. Use --setup-only to repair your configured collection or add --refresh-catalog when listing/installing languages. Installing the full catalogue can take several gigabytes and substantial time.


Remove language?
Both translation directions and cached downloads will be deleted. You can reinstall this language later.
