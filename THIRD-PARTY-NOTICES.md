Translation model packages are original archives obtained from https://argos-net.com/ and cataloged at https://github.com/argosopentech/argospm-index. The application reads their CTranslate2 weights and tokenizer data directly. The package format does not require installing its original wrapper library. Model README attribution is preserved both in the archives and in model-notices. Many original OPUS-MT models identify CC-BY 4.0; other package notices contain dataset attribution without an explicit aggregate weight license. No new blanket license is asserted for the weights.

OPUS-MT authors: Jörg Tiedemann and Santhosh Thottingal, “OPUS-MT — Building open translation services for the World”, EAMT 2020. Additional authors and datasets are listed in the unchanged model notices. Preserve them when redistributing models.
